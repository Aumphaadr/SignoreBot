# SignoreBot — история версий

Номер версии живёт в трёх местах и должен совпадать: `package.json`,
`src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`. Проверка обновлений
сравнивает его с тегом последнего релиза GitHub (`v1.2.3` или `1.2.3`).

## 1.0.4 — 2026-09-06

- **Наборы медиа: случайный файл из набора.** На вкладке «Медиа» появился
  блок «Наборы»: набор — список файлов, файл может входить в несколько
  наборов («В набор…» у каждого файла, фильтр по набору, капсулы наборов на
  карточках). В редакторе медиа переключатель «Один файл» / «Случайный из
  набора»: при каждом срабатывании один из файлов набора, все по разу,
  потом заново в новом порядке, без повторов подряд. Предпросмотр показывает
  случайный файл с кнопкой «Другой». Смешанные и пустые наборы не
  запрещены, но помечены и объяснены. Файл в наборе считается используемым;
  удаление файла вычищает его из наборов. Старые конфиги не меняются, пока
  набор не создан. Клик по файлу на вкладке «Медиа» открывает окно файла:
  предпросмотр без автозапуска (пуск кнопкой плеера), галочки наборов с кнопкой «Сохранить» и
  кнопка «Удалить файл».
- Бот видит, запрашивал ли OBS страницу оверлея и прошёл ли ключ.
  Предупреждение «оверлеи не подключены» стало коротким: кто не подключён и
  одна причина; подробное объяснение и что нажать — в подсказке капсулы на
  карточке самого оверлея на вкладке «Оверлеи» («адрес в OBS без ключа»,
  «страницу не запрашивали», «не подключён»). Офлайн-кэш страницы оверлея больше не запоминает ответы
  «неверный ключ» или «не найден» (например, от другого экземпляра бота
  на том же порту) вместо самой страницы.
- Когда OBS WebSocket не отвечает, лог и предупреждение говорят прямо: в
  OBS выключен сервер WebSocket или в настройках бота другой адрес или
  порт. Предупреждение «оверлеи не подключены» напоминает, что после смены
  порта, ключа или доступа из сети у Browser Source в OBS остаётся старый
  адрес. Переключатель «Доступ из локальной сети» предупреждает об этом
  сразу.
- «Логи»: кнопка копирования показанных записей в буфер обмена рядом с
  «Экспортом», поле поиска уже.
- **OBS раньше бота.** Перезагрузка Browser Source через OBS теперь идёт
  до предупреждения «оверлеи не подключены», а не одновременно с ним. Если
  имена источников не совпали с OBS, предупреждение называет, каких имён
  нет и какие Browser Source в OBS есть. Поле «Browser Source в OBS»
  подсказывает имена из OBS, а кнопка «Подобрать по адресам» заполняет
  привязки сама — по адресам оверлеев в источниках. Кнопка «В OBS» не
  перезаписывает адрес, если он уже такой (страница в OBS не моргает).
- Моноширинный шрифт панели — Source Code Pro (логи, переменные, адреса,
  ключи); значок ожидания у «подключение…» в боковой колонке, у EventSub
  на «Баллах канала» и на плитке ядра, пока бот просыпается.
- Награду, созданную через бота, можно удалить с канала из редактора
  реакции («Удалить награду на Twitch», с подтверждением); реакция при этом
  убирается.
- Страница-заглушка оверлея (когда OBS открыл адрес раньше самого первого
  запуска бота) стала прозрачной и сама перезагружается, как только бот
  ответит — обновлять источник вручную не нужно.
- Если окно панели не загрузилось и встроенный браузер показал «Connection
  refused» на белом фоне, через 8 секунд приложение объясняет диалогом,
  что бот при этом работает, называет обычные причины (VPN или прокси,
  перехватывающий локальные адреса, антивирус, повреждённый WebView2), путь
  к логам и предлагает перезагрузить панель. На Windows встроенный браузер
  панели больше не ходит через системный прокси.
- Редактор алиасов больше не пугает жёлтой плашкой «алиас работает только
  если команда включена» у включённой команды: предупреждение появляется
  только у выключенной и называет, какие алиасы не сработают.
- «Медиа»: кнопка удаления больше не открывает предпросмотр, а удаление
  файла закрывает его плеер. «Логи»: одна высота и одинаковые отступы у
  поля поиска, списков и кнопок, у «Экспорта» появилась подпись. «Баллы
  канала»: обе кнопки внизу одинаковые, ни одна не выглядит второстепенной.

## 1.0.3 — 2026-09-05

- **Кнопка «Тест» в шапке редактора** — у команд, наград, событий, периодики
  и резервной реакции оверлея. Выполняет реакцию как она настроена сейчас,
  без сохранения: текст уходит в чат, медиа — на оверлей; результат
  показывается уведомлением. Кнопка «Тест на оверлее» под предпросмотром
  убрана.
- **«Новая награда для Twitch»** на вкладке «Баллы канала»: награда
  создаётся на канале от имени бота (название, стоимость, подсказка, ввод
  текста, цвет, кулдаун, лимиты) и сразу открывается редактор реакции. У
  наград, созданных через бота, в редакторе есть блок «Параметры награды на
  Twitch» с кнопкой «Применить на Twitch». Картинку награде задают только в
  панели Twitch.
- **Алерт без файла.** Медиа-реакция может состоять из одного текста: он
  показывается на оверлее заданное время (поле «Длительность показа текста»).
- **Ответ реплаем и кулдаун на зрителя** у команд: «Отвечать реплаем на
  сообщение зрителя» и «На одного зрителя, с» рядом с общим кулдауном;
  капсулы на карточке показывают оба.
- **Масштаб панели** («Настройки → Масштаб панели»): 90–150 %, крупнее
  текст, значки и поля — для тех, кому мелко.
- Исправлено: если сообщение чата с наградой приходило раньше события
  погашения, учёт погашения (список невыполненных, возврат баллов,
  закрытие) не выполнялся. Теперь он довершается по событию.
- Исправлено: «Стоп» у неподключённого оверлея не сбрасывал отложенную
  очередь, а сам вставал в неё. Теперь очередь выбрасывается сразу.
- Сервер оверлеев по умолчанию слушает только этот компьютер (у уже
  установленных настройка не меняется); на вкладке «Оверлеи» — подсказка,
  где включить доступ из сети. Панель работает под строгой политикой CSP.
- Убран мёртвый код переподключения EventSub; значок меча модератора
  перерисован.
- **Сайт переписан**: девять коротких уроков от установки до наград за
  баллы, исходники в `site/`, сборка `npm run site`.
- Уведомления панели: не подпрыгивают при наведении, крестик крупнее и
  срабатывает с первого раза, клик по телу уведомления его больше не
  закрывает; держатся не меньше шести секунд (было три). Новый раздел
  «Настройки → Уведомления»: длительность и режим «не исчезать сами».
- Капсула «Вкл/Выкл» убрана у команд, наград, событий и периодических
  реакций — её подсказка переехала на кнопку включения. У наград стоимость — со значком баллов канала, награда,
  созданная через бота, помечена значком робота. Новые значки ролей в
  «Кто может вызывать»: меч модератора, гем VIP, звезда подписчика; Bits —
  свой значок.

## 1.0.2 — 2026-09-05

- **«Если недоступен».** Кнопка на карточке оверлея открывает редактор
  резервной реакции: текст в чат и/или медиа на другой оверлей, с
  переменными `{user}`, `{reaction}`, `{overlay}`; включается и выключается
  отдельным переключателем, состав при этом не теряется. Пока резерв
  включён, медиа для выключенного оверлея не ждёт в очереди 30 секунд, а
  сразу заменяется резервом. Подсказка при наведении показывает, что
  настроено; в редакторе — какие пункты включить у Browser Source в OBS,
  чтобы бот замечал выключенный источник.
- **Невыполненные погашения.** Награды за баллы, чьё медиа не дошло до
  оверлея, копятся в списке внизу вкладки «Баллы канала» с кнопкой в
  очередь запросов Twitch, где стример и модераторы возвращают баллы. Бот
  следит за очередью и убирает закрытые погашения сам.
- **Возврат баллов ботом** — флажок «Возвращать баллы, если оверлей
  недоступен» для наград, созданных через бота (правило Twitch: отменять
  погашения может только приложение-создатель). Для остальных — кнопка
  «Создать управляемую копию»: бот делает копию награды с теми же
  параметрами, переводит реакцию на неё, показывает, что удалить в панели
  Twitch, и после удаления оригинала сам возвращает копии прежнее название.
  Удачные погашения таких наград бот закрывает, чтобы очередь не копилась.
- Кнопка «Обновить до …» в левой колонке под состоянием бота — появляется,
  когда проверка (автоматическая или ручная) нашла новую версию, и открывает
  страницу релиза. Адрес в «Настройки → Обновления» принимает и прямую
  ссылку на JSON в формате GitHub — для форков со своим сервером.
- Награда с возвратом баллов больше не оставляет медиа в очереди
  выключенного оверлея: раньше зритель получал и баллы назад, и медиа через
  полминуты, когда оверлей включался.
- Карточки наград: капсула «Вкл/Выкл» убрана (её подсказка переехала на
  кнопку включения), стоимость — со значком баллов канала, награда,
  созданная через бота, помечена значком робота. Новые значки ролей в
  «Кто может вызывать»: меч модератора, гем VIP, звезда подписчика; Bits —
  свой значок.
- При запуске бот сверяет реакции со списком наград канала: награду,
  переименованную пока бот был выключен, панель показывает под новым
  названием, об удалённых — предупреждение в логе.
- Бот подписан на добавление, изменение и удаление наград на Twitch:
  удалённая награда сразу помечается «нет на канале» (реакция сохраняется),
  переименованная — получает новое название в панели.
- У стримера дополнительно запрашивается право `channel:manage:redemptions`
  (нужно только для возврата баллов); токены 1.0.1 продолжают работать,
  для возврата — авторизовать стримера заново.
- Проверка обновлений при запуске починена: раньше она срабатывала только
  если приложение открывалось на вкладке «Состояние». Теперь её делает само
  ядро через 20 секунд после запуска и дальше раз в 12 часов, пока
  приложение живёт в трее; плашка видна на любой вкладке.

## 1.0.1 — 2026-09-04

- **Один аккаунт на обе роли.** Переключатель «Бот — тот же аккаунт, что и
  стример» на вкладке «Авторизация»: сообщения идут в чат от имени стримера.
  Права бота теперь запрашиваются у стримера всегда, поэтому режим включается
  без повторной авторизации (заново — только для токенов, выданных до 1.0.1). Собственные команды стримера
  при этом работают: эхо бота отсеивается по идентификатору отправленного
  сообщения, а не по автору.
- Капсула «Все оверлеи» на карточках реакций и предупреждение в редакторе,
  когда целевой оверлей не выбран (иначе копия медиа уходила на каждый
  оверлей незаметно для пользователя).
- Подсказки у капсул на карточках команд, наград, событий и периодики: тексты
  собираются из ваших данных (алиасы, права, оверлей, кулдаун, смещение).
- Собственный набор иконок вместо Font Awesome и эмодзи; шрифт Jost;
  сдержанная палитра, заголовки светлым.
- **Шрифты для текста на оверлее встроены в приложение** — 14 семейств с
  кириллицей (Inter, Roboto, Montserrat, Noto Sans/Serif, Oswald, Comfortaa,
  Lobster, Neucha, Handjet и другие) вместо списка системных шрифтов Windows.
  Оверлей получает их с локального сервера, поэтому текст выглядит одинаково
  в предпросмотре и в OBS на любой ОС. В списке каждый шрифт показан собой.
  Прежние значения (Segoe UI и другие) продолжают работать как «свой шрифт».
- Стример и бот на одном аккаунте, папка данных, обновления — как в 1.0.0.
- Лицензия MIT, `THIRD-PARTY.md`.

## 1.0.0 — 2026-09-03

Первый релиз переписанного бота (Tauri 2 + Rust + React). Заменяет старую
связку Node-сервер + браузерная панель.

- Одно приложение с иконкой в трее; закрытие окна по выбору — в трей или выход.
- Twitch: Device Code Flow без секрета, токены в системном хранилище, чат и
  события через EventSub, отправка через Helix, автообновление токенов.
- Оверлеи: ключ доступа в URL, один порт для HTTP+WS, адреса через
  127.0.0.1 по умолчанию (порядок запуска OBS/бота не важен), очередь с
  антиспамом, предпросмотр в панели совпадает с оверлеем пиксель в пиксель.
- Команды (права ролями и списком), награды, события, периодика, шатауты
  с разбором ответов Twitch, банворды на Ахо-Корасик, заметки, логи с экспортом.
- Медиа: тип по содержимому, каталог с предпросмотром и уборкой сирот.
- Автоматическая миграция конфига старой версии (v1); экспорт/импорт без секретов.
- Настройки: папка данных на любом диске (с копированием), проверка
  обновлений по релизам GitHub.
- Сборки: Linux (.deb, AppImage), Windows (portable .exe).
- Одна копия приложения: повторный запуск показывает окно работающей. Две
  копии (старая в трее + новая) по очереди «протухали» одноразовые
  refresh-токены Twitch — отсюда частые «выкидывания» из аккаунтов.
- Перед refresh токен перечитывается из хранилища; при отказе keyring токен
  дублируется в `secrets.json`, чтобы не потеряться после перезапуска.
- Копирование в буфер через плагин Tauri: «Скопировать ссылку» при авторизации
  больше не падает с «The request is not allowed by the user agent…».

## До 1.0.0: март — июнь 2026

Восстановлено по снимкам (диффы между соседними снимками после нормализации форматирования).
Номеров версий тогда не было — заголовки по датам снимков, буква означает порядок внутри дня.

### 2026-03-21 — отправная точка

Node.js-сервер (Express, `tmi.js` для IRC, EventSub по WebSocket, `ws`,
`multer`) и React-панель на Vite. Уже умеет: команды с правами (стример,
модераторы, VIP, подписчики, список ников) и алиасами; реакции на награды за
баллы с буфером на время недоступности EventSub; события (фолловер,
подписка, переподписка, подарок, рейд); периодические сообщения по
интервалу; авто-шатауты по списку с кулдауном 125 с; банворды жёсткого и
мягкого режима с автоматическими вариантами написания (латиница, цифры,
повторы букв); медиа на оверлей с текстом поверх; несколько оверлеев с
адресами; случайный зритель из Helix с кэшем 60 с; логи по WebSocket в
панель; OAuth двух аккаунтов с обновлением токенов по расписанию. Панель —
семь вкладок сверху: Основное, Команды, Баллы канала, События,
Периодическое, Банворды, Логи. Единый редактор реакции «текст в чат + медиа
на оверлей» уже есть, старые редакторы по типам лежат мёртвым грузом.

### 2026-03-25 — уборка

- Удалены двенадцать неиспользуемых файлов: редакторы «текст», «медиа»,
  «смешанный» для команд, наград и периодики, редактор алиасов команд,
  выбор оверлея. Всё это заменил общий редактор реакции.

### 2026-03-26 (a) — новая панель

- Боковая колонка вместо вкладок сверху; девять разделов: Авторизация,
  Оверлеи, Команды, Баллы канала, События, Шатауты, Периодическое,
  Банворды, Логи. Экран загрузки с индикатором.
- «Основное» разобрано на три раздела. Авторизация: карточки стримера и
  бота, число прав, обновление токена, выход. Оверлеи: название и адрес,
  копирование URL, подсказка про допустимые символы. Шатауты: список для
  авто-шаута, статус очереди и кулдауна, ручной шатаут, сброс выполненных.
- Команды, награды, периодика и события редактируются в модальном окне по
  кнопке «Редактировать» вместо раскрывающихся карточек; на карточках
  капсулы «Вкл/Выкл», тип реакции, алиасы, оверлей.
- Редактор команды показывает, как команда будет доступна; редактор алиасов
  не даёт алиасу совпасть с существующей командой.
- Награды: сначала выбор награды из списка канала, потом реакция;
  переменная `{message}` для введённого текста.
- Медиа: список анимаций появления и ухода (плавно, сдвиги с четырёх
  сторон, увеличение и уменьшение), настройки шрифта текста, предупреждение
  про H.265, лимит файла 100 МБ.
- Банворды: карточки статистики (слов, вариантов), сворачиваемый список
  вариантов, переименование «алиасов» в «варианты написания».

### 2026-05-15 (a) — OBS и очередь для оверлеев

- Интеграция с OBS WebSocket (необязательная библиотека): через 15 с после
  старта проверка, все ли оверлеи открыты, дальше каждые 15 с; если нет —
  перезагрузка Browser Source через OBS до пяти раз с интервалом 30 с по
  привязкам «источник → оверлей»; понятные подсказки, если OBS не запущен,
  пароль неверный или источник не найден.
- Медиа для неподключённого оверлея ставится в очередь (30 с, до 20
  сообщений) и доставляется при подключении вместо потери.
- Service Worker кэширует страницу оверлея (для 127.0.0.1 и HTTPS), поэтому
  порядок запуска OBS и бота перестал быть важен; оверлей переподключается
  при возвращении сети и активации окна.
- Стартовый отчёт: «ядро готово», список ожидаемых и подключённых оверлеев.
